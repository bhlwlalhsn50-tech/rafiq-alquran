# رفيق القرآن — الإصدار التطويري 1.1.0

مشروع Android Studio أولي لتطبيق عربي باسم **رفيق القرآن**.

## ما أُضيف في هذه النسخة
- واجهة عربية محسنة واتجاه RTL.
- صفحات رئيسية، المصحف، جلسة الحفظ، المراجعة، الإنجازات، والإعدادات.
- البحث في أسماء السور وعرض الآيات من API خارجي.
- تشغيل تلاوة السورة من رابط صوتي خارجي.
- تحديد هدف يومي وعدد مرات التكرار.
- تسجيل جلسات الحفظ وإحصائيات محلية.
- حفظ آخر سورة مفتوحة وموضع قراءة تقريبي.
- وضع ليلي.
- تصدير إحصائيات التقدم كملف JSON.
- أيقونة متجهة أولية للتطبيق.

## فتح المشروع وبناء نسخة تجريبية
1. فك ضغط الملف.
2. افتح مجلد المشروع في Android Studio.
3. ثبّت Android SDK 36 عند الطلب، ثم نفّذ Gradle Sync.
4. شغّل التطبيق على محاكي أو هاتف أندرويد متصل بالكمبيوتر.
5. لبناء حزمة اختبار: Build > Build Bundle(s) / APK(s) > Build APK(s).

## حدود هذه النسخة — يجب إكمالها قبل Google Play
- هذا مشروع مصدر وليس AAB موقعاً أو تطبيقاً منشوراً.
- نص القرآن والتلاوة يتم جلبهما عبر الإنترنت من خدمات خارجية. يجب مراجعة مصدر النص ومطابقته مع مصحف موثوق ومراجعة حقوق وشروط استخدام النص والصوت قبل النشر.
- حفظ التقدم محلي فقط، ولا يوجد حساب مستخدم أو مزامنة سحابية.
- تذكيرات Android المجدولة لم تُنفذ بعد؛ صفحة الإعدادات تحتوي على الوضع الليلي فقط.
- يجب إجراء اختبارات على أجهزة فعلية، تحسين إدارة الأخطاء والعمل دون اتصال، وإضافة سياسة خصوصية ورابطها وإفصاحات البيانات ومواد المتجر.
- يجب مراجعة أحدث متطلبات Play Console وسياسات Google Play، إعداد توقيع إصدار آمن، ثم إنشاء AAB موقّع.
- الأيقونة الحالية متجهة أولية ويجب اعتمادها واختبار ظهورها على أحجام وأشكال مختلفة.
